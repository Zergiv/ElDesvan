## Desarrollo

Node.js v22 + [pnpm](https://pnpm.io/)

```console
git clone https://github.com/Zergiv/ElDesvan.git
cd ElDesvan
pnpm install
pnpm start
```

Build: `pnpm run dist` · Release: tag `vX.Y.Z` y push.

Basado en [HeliosLauncher](https://github.com/dscalzi/HeliosLauncher).
